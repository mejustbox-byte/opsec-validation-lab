# Live laboratory procedure

Provision a separate environment using the relevant auditor instructions. Record the auditor release, ruleset, environment version, scenario setup and an execution identifier in private evidence. Execute the auditor using its own supported entry point; this toolkit does not provision, connect or execute it.

Normalize the report with the supported report-contract adapter. Preserve unknown and unavailable statuses. Review artifacts for sensitive content before moving any material to a public workspace; write a new reviewed artifact and compute its hash after review. The manifest points only to that normalized JSON and declares the reviewed flag. A flag alone is not a substitute for review.

Compare with independently prepared expected identities and statuses. Retain private execution logs separately. If the environment was not provisioned, credentials unavailable, execution absent or normalization unsupported, record an empty report/hash live case. The result remains not_tested. No live environment was exercised for the initial local candidate.
