# План развития

Alpha реализует автономный потребитель манифеста и четыре проверки утверждений. Она принимает opsec-1.0 и не запускает платформенные аудиторы. Матрица приёмки проверяется синтетическими фикстурами и явно невыполненным live-сценарием.

Следующие этапы: независимо проверенные каталоги live-сценариев, документированное покрытие адаптеров существующих аудиторов, проверка подписей свидетельств и опциональная изолированная оркестрация. Каждая интеграция требует тестов совместимости производителя/версии и положительных, отрицательных и недоступных сценариев. Неявно они не включаются.

При расширении смысл pass не меняется: отсутствующее свидетельство остаётся not_tested, совпадение ожидаемого отказа означает только успешное утверждение. Заявления о реальной лаборатории требуют приватных журналов и проверяемых метаданных; публичные фикстуры остаются синтетическими.
