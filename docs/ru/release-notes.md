# Alpha 0.1.0a1

Реализованы ограниченный манифест lab-1.0, точное сравнение результатов/статусов, заявления о producer/platform, synthetic/live-классификация и флаг ручной проверки приватности. Выход содержит оценку opsec-1.0 и компактный каталог. CLI не исполняет команды манифеста.

19 тестовых методов покрывают утверждения, недоступные свидетельства, повреждённый вход, специальные файлы, лимиты и эксклюзивный выход. На Windows FIFO недоступен и соответствующий тест пропускается; это свидетельство для отдельной платформы, а не гарантия FIFO на всех ОС. Проверены локальные Linux/Python 3.12 и чистая установка wheel. Статус hosted CI фиксируется отдельно.

Ограничения: нет фактического запуска аудиторов, проверки живой среды, удостоверения provenance и автоматической очистки. Первичная установка использует отдельно выпущенный wheel контракта с опубликованным хешем. Публикация PyPI не включена. Prerelease не готов для production.
