# Требования

Лаборатория сравнивает предоставленный нормализованный отчёт с манифестом сценария. Она не запускает аудитор, сборщик, shell-команды или tenant API. Цель — сделать ожидаемые результаты, версии и класс свидетельств проверяемыми, не выдавая успех фикстуры за проверку инфраструктуры.

R1 требует точного совпадения идентичности и статуса результатов, включая дополнительные записи. R2 требует совпадения имени, версии и правил производителя, а также заявленных платформы и версии. R3 требует соответствия synthetic-флага классу сценария; для live дополнительно нужен идентификатор выполнения. R4 фиксирует булево заявление о ручной проверке приватности. Наличие секретов R4 не исследует.

Приёмка включает положительные и отрицательные сценарии для каждого утверждения, повреждённые манифесты, отсутствующие свидетельства, неверные хеши, невыполненные live-сценарии, коды CLI и эксклюзивное создание выхода. Отчёты соответствуют opsec-1.0. Сборщики и live-выполнение требуют отдельных решений и свидетельств.
