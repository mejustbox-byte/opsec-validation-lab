# Модель угроз и ограничения

Недоверенные манифесты и отчёты могут содержать повреждённые данные, чувствительные идентификаторы и ложные заявления. Строгая загрузка, лимиты размера/глубины, точные поля, имена файлов без каталогов и эксклюзивный выход уменьшают обычные ошибки. CLI выдаёт общие ошибки без повторения входного текста. Содержание манифеста не исполняется, URL не загружаются.

Остаются расход CPU/RAM в пределах лимитов, гонки файловой системы, hardlinks, компрометация runtime/зависимостей, ложные хеши/provenance и чувствительные ID. SHA-256 обнаруживает изменения только относительно предоставленного манифеста. Sanitization_reviewed — утверждение: секретный артефакт с этим флагом остаётся секретным. Инструмент не разрешает публикацию и не анонимизирует данные.

Недоступные и повреждённые свидетельства дают видимые пробелы покрытия. Ожидаемые fail/not_tested могут корректно совпадать со сценарием: pass LAB-001 означает лишь наблюдение ожидаемого результата. Из кода лаборатории нельзя вывести production readiness, полноту безопасности или фактическое состояние среды.
