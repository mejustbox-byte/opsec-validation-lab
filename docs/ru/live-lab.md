# Процедура живой лаборатории

Подготовьте отдельную среду по инструкции нужного аудитора. Сохраните версию аудитора, правила, версию среды, подготовку сценария и ID исполнения в приватных свидетельствах. Запустите аудитор его поддерживаемым способом; этот toolkit не создаёт среду, не подключается и не исполняет аудитор.

Нормализуйте отчёт поддерживаемым адаптером контракта, сохраняя unknown и unavailable. Проверьте артефакты на чувствительные данные до переноса в публичную рабочую область; создайте проверенный артефакт и вычислите хеш после проверки. Манифест ссылается только на этот JSON и заявляет флаг reviewed. Флаг не заменяет ручную проверку.

Сравните с независимо подготовленными ожидаемыми идентичностями и статусами. Приватные журналы сохраняйте отдельно. Если среда не подготовлена, нет учётных данных/исполнения или нормализация не поддержана, укажите live-сценарий с пустыми report/hash: результат остаётся not_tested. Для первоначального локального кандидата живая среда не испытывалась.
