# ADR-001: автономный Python-потребитель

Принято для alpha: Python 3.12+, JSON-манифесты, unittest и выпущенный opsec-report-contract 0.1.0a1. Повторное использование контракта исключает независимую реализацию статусов, покрытия и валидации отчёта. Версия зависимости точная; установка начинает с проверенного GitHub wheel, поскольку выпуск не опубликован в PyPI.

Bootstrap requirement содержит опубликованный SHA-256 wheel. Он подтверждает совпадение байтов с выпуском, но не доверие разработчику и не защиту от компрометации цепочки зависимостей. Сборка закрепляет setuptools 84.0.0 и wheel 0.48.0. CI использует Python 3.13 на трёх ОС; локальные проверки также используют 3.12.

Исключены из alpha: произвольный запуск команд, YAML с прикладными тегами, удалённые URL артефактов в манифесте и встроенные учётные данные. Это добавило бы исполнение и работу с секретами за пределами автономного потребителя. Подготовка VM/tenant и запуск настоящих аудиторов остаются будущими интеграциями.
