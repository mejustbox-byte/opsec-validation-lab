# Архитектура

CLI загружает ограниченный строгий JSON через загрузчик контракта отчётов. Валидация манифеста отвергает неизвестные поля, повторные ID сценариев, повторные ожидаемые пары, неподдерживаемые статусы и вложенные/абсолютные пути. Каждый отчёт — одно JSON-имя в каталоге манифеста. Принимаются до 256 сценариев и 10 000 ожидаемых пар на сценарий; зависимость ограничивает каждый JSON 8 MiB и глубиной 64.

Оценщик валидирует нормализованный отчёт и сверяет SHA-256 его байтов. Второй разбор сравнивается с загруженным объектом для обнаружения различий между чтениями. Это уменьшает несогласованность, но не создаёт свободную от гонок песочницу. Symlink-предки запрещены; hardlinks, параллельная замена и привилегированный атакующий вне гарантии.

Выход содержит оценку opsec-1.0 и компактный каталог сценариев. Пути отчётов, свидетельства и сообщения производителя не копируются. Пользовательские ID сценариев и набора могут раскрывать информацию. Оценка лаборатории помечается synthetic, поскольку проверяет предоставленные заявления; классы отдельных сценариев сохраняются в каталоге.
