# Матрица проверок

| ID | Условие pass | Отрицательный/недоступный случай | Ограничение |
|---|---|---|---|
| LAB-001 | Точная карта идентичности/статусов | Другой статус, пропавшая или лишняя пара | Только предоставленные ожидания |
| LAB-002 | Точный producer и заполненная платформа | Другая версия или пустая платформа | Платформа заявлена |
| LAB-003 | Совпадающий класс свидетельства | Synthetic/live-конфликт; нет live execution ID | Исполнение не удостоверяется |
| LAB-004 | Флаг ручной проверки true | False остаётся not_tested | Нет автоматической очистки |

Повреждённое свидетельство оставляет все четыре проверки not_tested и никогда не даёт pass. Повреждённый манифест — ошибка команды без оценки. Fail имеет приоритет над неполным покрытием в коде выхода. Каталог различает invalid_evidence и unavailable без копирования сырых ошибок разбора.

Тесты покрывают положительные утверждения, несовпадения статуса/идентичности, версии/платформы, конфликт класса, отсутствие выполнения/ручной проверки, неверный digest, повреждённый JSON, traversal, дубликаты, неверные типы и конфликт выходного файла. Они не подтверждают работу реальных AD, cloud, network или recovery.
